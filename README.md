## 🇹🇼 專案簡介 (Project Overview)

本專案是一個專門針對 **近年台灣詐騙案件與手法** 進行整合分析的靜態網站。

身為 **金融服務從業人員**，深感詐騙對民眾資產安全的巨大威脅，因此建立此平台。本網站整合了政府公開資料 (Open Data) 與 **內政部警政署 165 反詐騙儀表板**，旨在提供一個快速查詢、易於閱讀的「防詐懶人包」，協助大眾了解最新詐騙趨勢，進而保護自身財產安全。

### 核心功能 (Key Features)
* **🛡 詐騙趨勢分析**：深入解析電話詐騙、網購詐騙、假交友與投資詐騙等常見手法與特徵。
* **📊 即時數據整合**：內嵌 **165 打詐儀表板**，提供即時的案件統計、財損金額與高發縣市數據。
* **📱 防詐資源串接**：提供警政服務 App 下載入口（iOS/Android）與官方 LINE/Facebook 防詐社群連結。
* **🔍 SEO 搜尋優化**：針對搜尋引擎進行深度優化，讓有需要的民眾能更容易找到正確的防詐資訊。

## 🛠 技術規格與實作細節 (Technical Specifications)

本網站採用輕量化的靜態網頁架構，專注於效能優化與使用者體驗。

### 1. 網頁架構與設計 (Architecture & Design)
* **核心技術**：HTML5, CSS3 (Pure CSS, No Frameworks)。
* **響應式設計 (RWD)**：使用 `clamp()` 函數與 Flexbox 彈性佈局，確保網站在桌機、平板與手機上皆能完美顯示，提供最佳閱讀體驗。
* **效能優化**：針對外部嵌入內容（如儀表板 iframe）實作 `loading="lazy"` 懶加載技術，提升網頁開啟速度。

### 2. SEO 與社群優化 (SEO & Social Sharing)
* **Meta Tags**：完整的 Title, Description 與 Keywords 設定，針對「165」、「詐騙分析」、「投資詐騙」等關鍵字進行佈局。
* **Open Graph (OG)**：優化 Facebook 與 LINE 的分享預覽效果，包含自定義封面圖 (`cover.jpg`) 與標題，增加社群傳播力。
* **結構化資料**：實作 `Schema.org` (JSON-LD)，明確定義網站性質與作者資訊，提升 Google 搜尋結果的專業度。

### 3. 資料來源 (Data Sources)
* **政府資料開放平台 (data.gov.tw)**：作為基礎數據分析來源。
* **內政部警政署 165 全民防騙網**：提供即時儀表板數據。

## 🇬🇧 English Introduction

# 2025 Fraud Prevention & Data Analysis Website

This project is a static website dedicated to analyzing **recent fraud trends and techniques in Taiwan**.

As a **Financial Advisor**, I recognize the significant threat fraud poses to personal assets. This platform integrates government Open Data and the **165 Anti-Fraud Dashboard** to serve as a comprehensive guide ("Lazy Package"). Its goal is to help the public stay informed about the latest scams and improve their fraud awareness to protect their financial well-being.

### Key Features
* **Trend Analysis:** Detailed categorization of phone scams, online shopping fraud, social media scams, and investment scams.
* **Real-time Data:** Integration of the official **165 Dashboard** via iframe for live statistics on fraud cases and financial losses.
* **Resource Hub:** Quick links to download the Police Service App and join official anti-fraud social communities.
* **SEO Optimized:** Enhanced with JSON-LD and Open Graph tags for better search visibility and social sharing.

### Tech Stack
* **Frontend:** HTML5, CSS3 (Responsive Design with Flexbox).
* **Hosting:** GitHub Pages.
* **Optimization:** Implemented `loading="lazy"` for iframes and Semantic HTML tags for better accessibility and performance.
