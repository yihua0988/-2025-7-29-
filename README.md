# 近年詐騙防制資料分析網站

## 專案簡介

本專案是一個專門針對 **近年詐騙案件與手法** 進行分析的資料網站，目的是透過政府公開資料及新聞案例，深入了解詐騙趨勢，提供可視化儀表板與統計分析，協助民眾、金融機構及相關單位提升防詐意識與決策效率。  

網站涵蓋以下功能：
- 詐騙案件數據整理與分析
- 電話、網購與社群媒體詐騙模式分類
- 165 反詐儀表板整合
- App QR Code 推廣警政服務及防詐社群
- 作品索引與簡報連結

## 設計規格與技術細節

### 🎨 背景顏色
全站統一使用 **水藍色 (#9DE1F2)**，營造清新、專業感，並確保文字與圖表的易讀性。

### 📝 字體設定
全站文字統一採用 **思源黑體 (Noto Sans TC / Source Han Sans)**，並搭配系統字體（如 Microsoft JhengHei、Arial）作為後援，以確保不同裝置和作業系統上的顯示一致性與美觀。

### 🖥 導覽列
- 導覽列固定於頁首，提供首頁、分析專頁、反詐宣導及總結頁面快速切換。
- 使用透明白底與模糊效果，保持簡潔，並支援響應式排列。  
- 按鈕為藍色背景、白色文字，懸停時加深色調，點擊有輕微位移效果。

### 📊 主要內容區
- 主標題及副標題使用大字體，強調專案核心概念。
- 段落文字兩端對齊，方便長文閱讀。
- 表格設計為無格線、分類文字放大、數據文字靠左，並有底線分隔。

### 📈 Power BI / 165 儀表板
- 內嵌 iframe 顯示 165 反詐儀表板，寬度自適應，高度 900px。
- 提供來源連結至官方網站，以方便使用者查看原始資料。

### 📱 App QR Code
- 提供 **警政服務 App** iOS/Android 下載及社群平台 QR Code。
- 使用彈性盒排列，支援多裝置螢幕，圖片統一尺寸，附說明文字。

## 英文介紹 (English)

# Anti-Fraud Data Analysis Website (Recent Years)

## Project Overview

This project is a dedicated data analysis website focused on **recent fraud cases and techniques**.  
The website uses government open data and news examples to provide insights into fraud trends, visualize statistics, and help the public, financial institutions, and authorities enhance anti-fraud awareness and decision-making efficiency.

Features:
- Data collection and analysis of fraud cases
- Categorization of fraud patterns: phone scams, online shopping scams, and social media scams
- Integration of the 165 Anti-Fraud Dashboard
- QR Codes for downloading police service apps and joining anti-fraud communities
- Project repository and presentation slides

## Design & Technical Specifications

### 🎨 Background Color
- Unified **light blue (#9DE1F2)** across the site, providing a fresh and professional appearance while ensuring readability.

### 📝 Font Settings
- Main font: **Noto Sans TC / Source Han Sans**  
- Fallback fonts: Microsoft JhengHei, Arial  
- Ensures consistent display across different devices and systems.

### 🖥 Navigation Bar
- Fixed at the top, with links to Home, Fraud Analysis, Anti-Fraud Awareness, and Summary pages.
- Transparent white background with blur effect, responsive design.
- Blue buttons with white text; hover effect darkens background; click effect gives slight movement.

### 📊 Main Content
- Large headings highlight project focus.
- Paragraphs justified for easy reading.
- Tables designed with no borders, enlarged category text, left-aligned data, and bottom border separator.

### 📈 Power BI / 165 Dashboard
- Embedded iframe for the official 165 Anti-Fraud Dashboard.
- Responsive width, height 900px.
- Includes official source link for reference.

### 📱 App QR Codes
- Download links for iOS/Android police service apps and social media groups.
- Flexible layout using CSS flexbox; images uniform in size with description text.
